# 防空ミサイル性能向上プロジェクト計画

## 1. 目的

Stormworks上の防空ミサイルについて、ビーム機動を行う目標を終末誘導用レーダーの視野内に保持し、追尾と迎撃の再現性を高める。

## 2. 問題定義

ユーザーが確認している現象：

- ビーム機動を行う目標に対して追尾が甘くなる。
- 比例航法中に、終末誘導用レーダーの視野角内へ目標を保持できない。
- 後方追尾の近距離では、目標だけを未来へ予測して自機位置を現在値のまま使う時刻不整合が追尾を不安定にしていた。自機位置も同じ時刻へ予測する改良は、反復試験で高い命中率を維持したため正式採用した。
- 旋回中は未来の目標・自機位置を現在姿勢でローカル変換する時刻不整合も残るため、自機姿勢の遅延予測を試験版として実装した。ゲーム内効果と退行は未確認。

初期の因果仮説：

1. 誘導指令または機体姿勢の変化に対して、レーダー指向あるいはFOV余裕が不足する。
2. 目標がFOV外へ出る。
3. レーダー観測が途切れる。
4. EKFが予測のみとなるか、目標トラックを失う。
5. 終末誘導精度が低下する。

この因果列は試験で確認する。現時点では、どの段階が支配的かは未確定である。

## 3. 現行システムの構成

```text
データリンク目標位置・速度
          |
          v
ADSV3 MissileKF.lua
  - レーダー観測の座標変換
  - EKFとデータアソシエーション
  - 追跡目標の選択
  - レーダービーム指向角の算出
          |
          | 推定位置・速度、状態、ビーム指向
          v
ADSV3 Missile.lua
  - 発射・上昇シーケンス
  - 単追尾 / PN
  - 終末レーダーへのハンドオフ
  - フィン・信管出力

既存信号の分岐
          |
          v
ADSV3 MissileFOVDebug.lua
  - 経路差1 tickを考慮したFOV余裕
  - 追跡対象IDによる時分割データリンクの選別
  - 生レーダー観測のロスト・再捕捉
  - KF位置の1 tick予測残差と速度変化
  - DebugViewログのみ（出力なし）
```

## 4. 静的確認で分かっていること

- `ADSV3 MissileKF.lua` は推定目標位置をミサイルローカル座標へ変換し、`radarManualSweepX/Y` を出力する。
- `ADSV3 Missile.lua` は `MISSILE_FIN_DISTANCE_THRESHOLD` の距離条件が初めて成立した時点で、目標速度方向と「目標からミサイルへの方向」がなす3次元アスペクト角が `MISSILE_RADAR_MAX_ANGLE` 未満なら `missileRadarIO` を有効化する。角度がしきい値以上なら無効ラッチを立て、その発射中は以後有効化しない。
- `missileRadarIO` 有効後は、中間誘導用のyaw/pitch指令をゼロにした後、重力補償だけを加算する。
- `ADSV3 Missile.lua` は目標検出入力を、終末レーダー検出中に中間誘導フィンを抑止する条件として使用する。
- 終末レーダー検出中信号はKFのbool 32を通して誘導Luaへ渡し、KFの追跡有効bool 1とは分離している。
- FOV計測は文字数制限のためKF本体から分離し、`ADSV3 MissileFOVDebug.lua` が既存信号だけを読み取る。
- 現行コードでは `isPPN == true` が単追尾、`isPPN == false` がLOS角速度を使うPNを表す。
- 目標位置は `LOGIC_DELAY` tick先へ予測される。自機位置もPhysics Sensor位置の速度・加速度差分から同じ時間だけ予測し、KFのビーム指向と誘導Luaの目標相対幾何に使用する。
- 試験版では自機クォータニオンも1 tick差分から同じ時間だけ予測し、KFの追跡中ビーム指向と誘導Luaのpursuit/PN座標変換に使用する。生レーダー観測、EKF、KF出力姿勢、FOVロガー、実速度のローカル変換、重力補償は現在姿勢を維持する。
- 現在の終末レーダーFOV設定は水平全幅18°、垂直全幅86.4°、オフセット0°。
- `LOGIC_DELAY=4` の自機位置予測A/B試験では、変更前が近距離でFOV離脱後に自爆し、改良版は主終末レーダーのFOV離脱・生観測ロストなしで命中した。複数回の反復試験でも改良版は高い命中率を維持した。
- 改良版は全接近角度と `LOGIC_DELAY=3～5` でも高い命中率を維持し、試験した3値の明確な性能差は確認できなかった。
- HGV失敗試験では、生レーダー観測が存在したまま終末で主トラックへの割当が途切れ、予測継続後にトラックが交換された。試験版では、固定中の主トラックだけ観測残差方向によるepsilon増幅を無効化し、通常のマハラノビスゲートだけで判定する。
- 誘導に使うミサイルフィンの入力範囲は±10である。操舵飽和ログもこの範囲を基準とする。
- HGV直交交差の失敗ログでは、終末500 m以内の生観測と主トラックは維持されたが、約300 mから相対横速度が増え、約60 m以近で距離に対する方向転換要求がAA実横加速度を上回った。診断版として、対空PNの300～100 mだけ実効ゲインを最大1.5へ増やす限定ゲインスケジュールを追加した。

これらはコードと仕様の確認結果であり、問題原因の優先順位を確定するものではない。

## 5. 調査する候補

優先順は基準試験の結果から決める。

- 終末レーダー有効化の時期とハンドオフ条件
- レーダービーム指向の追従遅延、符号、角度単位
- 機軸基準FOVとビーム指向基準FOVの取り扱い
- PN指令による機体姿勢変化とシーカー視線の関係
- 目標ロスト時の誘導継続・再捕捉ロジック
- EKF予測誤差とレーダー再捕捉用ゲート
- PNと単追尾の切替条件・ヒステリシス
- ロジック遅延補償値の妥当性
- 試験版の自機姿勢予測が有効になる旋回率・接近角度と、無機動目標への退行有無
