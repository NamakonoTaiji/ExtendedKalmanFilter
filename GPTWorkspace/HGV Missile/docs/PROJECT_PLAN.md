# HGV機動対艦ミサイル開発計画

## 1. 目的

Stormworks内で、敵艦のSAMを限定方向に警戒し、脅威に対するビーム機動と再現可能な上下機動を行った後、敵艦へ終末突入する対艦ミサイルを開発する。

性能はゲーム内で観測できる軌道・速度・加速度・旋回を基準に定義し、現実の兵器性能を推測して再現しない。

## 2. 完成条件

- 同じ設定から同じ探索・機動・終末遷移を再現できる
- 敵艦方向約±30度を3 tickで探索できる
- 250 m/s未満またはHGVへ接近しない目標をSAMとして扱わない
- 有効SAMの推定水平速度に直交するビーム機動を行い、通常HGVでは上下蛇行を重ね、失探または通過で解除する
- 通常HGVのSEARCHとEVADEで上下蛇行を90 tickごとに反転できる
- 通常モードは敵艦までの水平距離1500 m以下でTERMINALへ不可逆遷移する
- シースキミングモードは高度20 mで進み、水平1000 mでポップアップ、高度400 mまたは目標3D距離500 m未満で突入へ移る
- 指令値だけでなく、実際の軌道・速度・加速度・角速度・飽和をログで確認できる
- HGV単体試験を完了してから防空ミサイルとの連携試験へ進む

命中回避率はHGV単体の完成条件に含めず、防空システムとの連携試験で評価する。

## 3. 採用要求

| 項目 | 採用値 |
|---|---:|
| シミュレーション周期 | 60 tick/s |
| レーダー有効射程 | 1900 m |
| レーダー探知間隔 | 1 tick |
| 指向範囲 | 方位±180度、仰角±45度 |
| ビーム全幅 | 水平21.6度、垂直75.6度 |
| 探索範囲 | データリンク敵艦方位の約±30度 |
| 探索指向点 | -20度、0度、+20度 |
| SEARCH仰角中心 | クランプ後の敵艦仰角と水平0度の中間 |
| 全探索時間 | 3 tick、0.05 s |
| SAM最低速度 | 250 m/s |
| 巡航基準高度 | 2000 m |
| 上下反転間隔 | 90 tick、1.5 s |
| 通常モードTERMINAL開始 | 敵艦までの水平距離1500 m以下 |
| シースキミング入力経路 | Radar Bool入力2 → Radar Bool出力5 / Guidance Bool入力5 |
| シースキミング高度 | 20 m |
| ポップアップ開始 | 敵艦までの水平距離1000 m以下 |
| ポップアップ高度 | 400 m |
| 突入開始 | 高度400 m以上、または敵艦までの3D距離500 m未満 |

上下蛇行の高度振幅は機体試験前のため `TBD`。

## 4. 採用構成

```text
データリンク敵艦位置・速度 ─┐
レーダー観測 ───────────┼─> HGV Radar.lua
Physics Sensor ──────────┘    - 3点探索
                                - 候補・SAM追跡
                                - SEARCH/CANDIDATE/EVADE/TERMINAL
                                           |
                                           v
                               HGV Guidance.lua
                                - 上下蛇行
                                - SAM進路に直交する水平ビーム機動
                                - 終末比例航法
                                           |
                                           v
                                      Yaw/Pitchフィン
```

読みやすいLuaを開発上の正本とし、LifeBoat圧縮版は配備・文字数確認用とする。

## 5. 開発範囲

対象：

- データリンク中間誘導
- 敵艦中心の限定レーダー探索
- SAM候補確認・選別・追尾
- SAM推定水平速度に直交するビーム機動
- 高度2000 mを中心とする上下蛇行
- 水平1500 mからの終末誘導
- 選択式の高度20 mシースキミング、ポップアップ、終末突入
- 機体限界、ロスト、通過、状態遷移の診断ログ

対象外：

- `AA Missile`のコード変更
- 防空システム・データリンク送信側の変更
- 実在兵器の性能主張
- 未計測の機体能力を前提にしたゲイン確定
