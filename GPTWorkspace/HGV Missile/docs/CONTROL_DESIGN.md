# HGV対艦ミサイル制御設計

## 1. 採用状態

本書の数値はユーザー合意済みの初期設計値である。機体能力に依存する制御ゲイン、フィン上限、上下蛇行の高度振幅は、Stormworks単体試験前のため `TBD` とする。
現行ソースのシースキミング高度10 m、プロパティ指定ポップアップ距離・高度、DIVE距離700 mは初期合意値と異なるため、最終採用確認を `TBD` とする。

## 2. 時間・座標・角度

- シミュレーション周期：60 tick/s、`dt = 1/60 s`
- 世界座標：X東、Y上、Z北、左手系
- 想定機体ローカル座標：X右、Y上、Z前（実機符号確認はTBD）
- レーダー指向入力：turns
- レーダー観測角：turns。指向ビーム中心ではなくレーダー筐体正面基準
- 内部ベクトル・角速度計算：rad

## 3. レーダー仕様

- 有効射程：1900 m
- 探知間隔：1 tick
- 指向中心の可動範囲：方位は左右±180度、仰角は±45度
- 瞬時ビーム全幅：水平21.6度、垂直75.6度
- 瞬時ビーム半幅：水平±10.8度、垂直±37.8度
- 探索中心：データリンクで受信・外挿した敵艦方向
- 水平探索範囲：敵艦方向の±30度付近

### 3.1 高速探索パターン

水平指向オフセットを `-20度、0度、+20度` の3点とし、各点を1 tick照射する。ビーム端を含む探索範囲は敵艦方位に対して約 `-30.8度～+30.8度` となり、隣接ビームは約1.6度重なる。

- 全探索更新：3 tick、0.05 s
- 同一端点の再訪：3 tick
- SEARCH仰角中心：指向上限へクランプした敵艦仰角と水平0度の中間、すなわち敵艦指向仰角の1/2
- 垂直75.6度ビームで、敵艦のSAM発射位置からHGV高度付近の水平線までを同時に覆う
- 指向方位はループ可能なため、`+20度` から `-20度` への電子走査を許容する

## 4. 状態遷移

優先順位は `TERMINAL > EVADE > CANDIDATE > SEARCH` とする。シースキミングのPOPUP / DIVEはTERMINAL内部の不可逆サブ状態とする。

### SEARCH

- 条件：発射済み、通常モードでは水平距離1500 m超、シースキミングでは1000 m超、有効SAMなし、候補確認中でない
- レーダー：3点高速探索
- 飛行：通常モードは高度2000 mを中心に上下蛇行。シースキミングは高度20 m固定で上下蛇行しない
- 上下反転間隔：90 tick（1.5 s）
- 完全な上下1周期：180 tick（3.0 s）
- 高度目標：通常は `2000 m ± VERTICAL_MANEUVER_AMPLITUDE_M`、シースキミングは世界Y高度20 m
- 高度振幅：TBD

### CANDIDATE

- SEARCH中に敵艦トラック以外のレーダー目標を得たら遷移
- レーダーを候補の予測位置へ固定し、速度と進行方向を推定する
- 候補確認中は上下蛇行を停止し、通常は高度2000 m、シースキミングは高度20 mを指令する
- 条件不成立または確認期限切れならSEARCHへ戻る

### EVADE

候補が次をすべて満たした場合に遷移する。

1. 推定速度が250 m/s以上
2. 速度ベクトルと「SAMからHGV」へのベクトルの内積が正
3. 相対位置 `r = p_sam - p_hgv` と相対速度 `v_rel = v_sam - v_hgv` に対し `dot(r, v_rel) < 0`

飛行はSAM推定水平速度に直交する2方向から、敵艦方向への進行成分が大きい側を選ぶ。1つのSAMトラックに対して回避側を固定し、SAMの速度方向が変化しても同じ側の直交方向を毎tick再計算する。水平速度が無効な場合だけSAMへの水平LOSを代替基準とする。通常HGVは高度2000 mを中心にSEARCHと同じ90 tick反転の上下蛇行を重ね、シースキミングは設定高度を固定する。レーダーはSAM予測位置を追尾する。

終了条件：

- レーダー追尾中に連続3 tick失探した
- 接近履歴を持つSAMについて `dot(r, v_rel)` が負から0以上へ変化し、最接近点を通過した
- TERMINAL条件を満たした（TERMINALを優先）

### TERMINAL

- 通常モード進入条件：データリンク敵艦位置との水平距離が1500 m以下
- シースキミング進入条件：データリンク敵艦位置との水平距離が1000 m以下
- 一度進入したら解除せず、SAM回避と上下蛇行を終了する
- レーダー指向を毎tick敵艦方向へ更新する
- 敵艦レーダートラックがデータリンクゲート内にあれば観測トラックを使用し、それ以外はデータリンク位置を使用する

シースキミングTERMINALは次のサブ状態を持つ。

- POPUP：敵艦の水平位置、世界Y高度400 mを純追尾する
- DIVE開始条件：自機高度400 m以上、または敵艦との3D距離500 m未満
- POPUP中は純追尾、DIVE移行後は敵艦への比例航法を使用する
- DIVEはラッチし、再びPOPUPへ戻らない
- 通常モードは従来どおりTERMINAL進入直後から敵艦への比例航法を使用する

## 5. 流用と分割

- `HGV Radar.lua`：`ADSV3 MissileKF.lua`のデータリンク、座標変換、追跡分割を基に、敵艦中心探索とSAM選別を担当
- `HGV Guidance.lua`：`ADSV3 Missile.lua`の単追尾、比例航法、重力補償を基に、上下蛇行・ビーム機動・終末誘導を担当
- 元の `ADSV3 Missile*.lua` は比較用として保持し、直接上書きしない
